# 01 Install Claude Code and open the kit

**Who:** you. **Time:** about 10 minutes.

1. **Download the kit.** On the kit's GitHub page, click the green **Code** button, then **Download ZIP**. Find the ZIP in your Downloads folder, right-click it and choose **Extract all** (Windows) or double-click it (Mac). Move the unzipped folder somewhere easy to find, for example `Documents/research-kit`.
2. **Install Claude Code.** Go to https://claude.ai/download, download the desktop app for your computer, install it, and sign in.
3. **Open the kit folder.** In Claude Code, choose to open a folder (or project) and select the unzipped kit folder. You know it worked when Claude Code shows the folder's name and a chat box.
4. **Say hello.** Type `hello` in the chat box. The AI guide should offer to run the setup.

## What is a command?
A command is a word starting with `/` that you type in the chat box, such as `/setup`. When you type `/`, Claude Code shows a list of the available commands, and you can pick one. You can also just describe what you want in plain words ("I want to add a new document"), and the AI guide will recognise the step.

## Good to know
- The AI guide always tells you which files it created or changed, and ends with a **Next step** line.
- Everything stays in this folder on your computer. Your documents are never uploaded anywhere, except to NotebookLM when you upload them yourself.

# 02 Sources

**Filled by:** you (the documents) and the AI guide (the register).

- Put each document in the subfolder for its theme, for example `02_sources/causes/`.
- Record every document in `source_register.csv` by typing `/add-source`. Each one gets an id: S01, S02…
- Use PDFs that contain selectable text. To check, open the PDF and try to highlight a word. If you can't, the file is a scanned image and NotebookLM may not read it well.

# Knowledge Package Starter Kit

A ready-to-use research workspace that helps you answer research questions from a set of documents, with every finding traced to a quote, a source and a page. An AI guide (Claude Code) sets it up with you and files everything, and NotebookLM answers your questions from your own documents. No coding needed.

## Start here: [START_HERE.md](START_HERE.md)

Download the kit (green **Code** button → **Download ZIP**), open the folder in Claude Code, and type `/setup`.

## What's inside

| Folder or file | What it is |
|---|---|
| [START_HERE.md](START_HERE.md) | Your first read: what you need and the three steps to begin |
| [guide/](guide/) | The step-by-step guide, in plain language |
| [prompts/notebooklm/](prompts/notebooklm/) | Ready-made prompts to paste into NotebookLM |
| [example-mexico-displacement/](example-mexico-displacement/) | **Worked example:** forced displacement in Mexico, set up with real sources and questions |
| `projects/` | Where your own projects are created (kept on your computer, never uploaded) |
| `project-template/` | The empty workspace that setup copies |
| `CLAUDE.md`, `.claude/commands/`, `prompts/ai-assistant/` | Instructions the AI guide follows |
| [advanced/](advanced/) | Optional tool for technical users (automatic quote checking); not needed |

## How it works

**Set up → add sources → plan notebooks → ask NotebookLM → save answers → track progress → summarize.** You repeat the ask-and-save steps until your questions are answered. See [guide/00_overview.md](guide/00_overview.md).

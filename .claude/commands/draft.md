Write a short working draft using only the evidence log. Follow `CLAUDE.md` rules throughout.

1. Find out which project (use the only one if there is just one).
2. Read `01_project-brief/project_profile.md`, `03_questions/question_bank.csv` and `07_evidence-log/evidence_log.csv`.
3. Write `08_outputs/YYYY-MM-DD_draft.md`:
   - The title, then the line: **Working draft – check against the sources before sharing.**
   - **One section per main question** from the project profile:
     - two to five sentences answering it;
     - every sentence ends with the finding ids it rests on, for example (F003, F007);
     - if no finding supports a point, leave the point out.
   - **A "Gaps" section:** every question marked `Needs follow-up`, and every one whose answer said NOT FOUND IN SOURCES.
   - **A "Sources" section:** the source ids used, with their titles from the register.
4. Never add a fact, number or source that is not in the evidence log. If the evidence is thin, say so in the draft.

List every file you created. End with a **Next step:** line, usually to check each cited finding against its answer file and source before sharing.
